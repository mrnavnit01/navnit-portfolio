# Navnit Maurya — Portfolio

A high-performance, production-ready portfolio website featuring a 60FPS canvas-based scroll sequence animation with 240 frames.

## Features
- 🎬 240-frame scroll-driven canvas animation (cover mode, zero black bars)
- ✨ Smooth header fade-out on scroll
- 🎨 Gold & dark luxury aesthetic with Google Fonts
- 📱 Fully responsive design
- 🔗 Working social links (Instagram, Gmail, LinkedIn, GitHub)

## Quick Start
```bash
npx http-server . -p 8080 -c-1
```
Then open [http://localhost:8080](http://localhost:8080)

## Deploy
Upload the entire root directory to any static hosting (Vercel, Netlify, GitHub Pages, Cloudflare Pages).
